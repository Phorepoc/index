Qt 4.8.7 for Phorepoc: QtCore, QtGui, QtNetwork (with SSL), QtSvg, QtXml, QtSql, QtScript, QtDeclarative (Qt Quick 1),
QtMultimedia, QtOpenGL, QtOpenVG, QtXmlPatterns, phonon, QtTest and Qt's plug-ins. Qt and Qt Quick apps made for
Symbian^3 need it; install it before them. Nothing in the system needs it.

No Phorepoc image carries Qt: it comes only from Catalogue. Qt is LGPL 2.1 with the Qt LGPL Exception 1.1; the package
installs the licence text, the exception and the source offer in `\resource\Qt\`.
